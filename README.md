# Мини-склад — учебная конфигурация 1С:Предприятие 8.3

Учебный проект для освоения разработки на платформе 1С:Предприятие 8.3. 
Реализован складской учёт: поступление товаров, отгрузка покупателям, 
хранение истории цен, отчёты по остаткам и продажам.

## 📦 Состав конфигурации

### Справочники
- **Номенклатура** — список товаров с артикулами.
- **Склады** — список складов.
- **Контрагенты** — поставщики и покупатели.
- **ЕдиницыИзмерения** — единицы измерения товаров.

### Документы
- **Поступление** — приход товара от поставщика на склад.
- **Отгрузка** — отгрузка товара покупателю со склада.

### Регистры сведений
- **ЦеныНоменклатуры** — история цен на товары (периодический, в пределах дня).

### Регистры накопления
- **ОстаткиТоваров** — остатки товаров в разрезе складов и номенклатуры.
  - Измерения: `Номенклатура`, `Склад`.
  - Ресурс: `Количество`.
- **Продажи** — обороты продаж в разрезе номенклатуры, склада и покупателя.
  - Измерения: `Номенклатура`, `Склад`, `Покупатель`.
  - Ресурсы: `Количество`, `Сумма`.

### Отчёты (СКД)
- **Остатки** — остатки товаров на дату, с группировкой `Склад → Номенклатура`.
- **Продажи** — продажи за период, с группировкой по покупателю и номенклатуре.

### Обработки
- **УвеличитьЦены** — массовое увеличение цен на заданный процент.

## 🛠️ Стек

- **Платформа:** 1С:Предприятие 8.3
- **Среда разработки:** Конфигуратор 1С
- **Язык:** встроенный язык 1С
- **Контроль версий:** Git (GitHub)

## 🚀 Как запустить

1. Установить 1С:Предприятие 8.3 (учебная версия).
2. Открыть Конфигуратор.
3. Загрузить конфигурацию из файлов (или создать новую и перенести объекты).
4. Обновить конфигурацию базы данных (`F7`).
5. Запустить Предприятие (`F5`).
